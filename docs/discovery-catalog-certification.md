# Published catalog certification (bounded support)

This adapter adds production observations, not a release exception. The fixed
22 scopes, price database, UI, daily/pin and successful-baseline rules are unchanged.

* Certificates expose seven separate obligations: population, pagination, literal
  identity, native channel, output, alias enumeration, lifecycle. Bare `complete`
  or `verified` flags and empty extraction never establish a negative universe.
  Identity/channel/output and alias/lifecycle also require per-ID qualified claims.
* OpenAI: the saved formal All models document is checked row by row, linked
  details and front-page-only cards reconciled. Snapshot does not imply alias,
  no-alias or active status. Explicit Alias for / Aliases: None / active status
  are supported. Unsupported grammar, dangling/chained aliases or unknowns block.
* xAI subscription: follow only the public documentation index's Build and
  Subscription sections, bounded to100 links. Config/BYOK examples, PAYG IDs and
  catalog placeholders never establish subscription membership. A formal native
  catalog table can provide partial, source-bound rows, not automatic completeness.
* Qwen: follow the three published category indexes and their literal model
  parameter/output detail declarations (at most180 distinct details). Input
  modalities and prefixes never establish outputs/provider. Category indexes
  are not a global/native/historical completeness assertion.
* Offline original HTTP export import: Qwen documented ListModels validates
  raw hashes, region/origin/server filters, every page, total, unique identities
  and response_modality. xAI documented /v1/models plus language/image/video
  models validates owner, literal aliases and explicit outputs. These are
  account-visible catalogs, never automatically global, subscription or retired
  history. No credential lookup, authentication or API calls are implemented.
  Offline imports never advance a fresh baseline.
* Access gates/401/403/429 stop subsequent document requests on that host; no
  challenge/header substitution. Captured gate bodies remain evidence, not models.

These are explicit reviewed grammar subsets, not general HTML/JSON-schema,
identity, alias or historical-universe solvers. Unknowns remain unknown. A
public directory being read completely does not prove that directory exhaustive.

* Unparsed directory entities and unrecognized alias/lifecycle declarations are retained as observations and keep the relevant obligation unknown; they never infer a legal ID/status and never close a certificate by omission.
* A modality certificate is verified only when that modality is present in per-ID `output_modalities`. A proven text output cannot complete an image/audio/video certificate. A snapshot is complete only if every declared modality certificate is complete.
* Offline xAI export `direct_alias_map` uses the same direct-alias invariant as shared projection: no chains, cycles, self-targets, conflicts or dangling targets. Successful maps remain account-visible evidence, never global, subscription or historical-universe proof.
